# Aeron Builds — a portfolio as a voxel game

My developer portfolio, built as a playable-looking game title screen. Everything
you see is generated at runtime: the 3D world, the block textures, and the
character skin. No engine, no libraries, no image files — three files and about
2,000 lines.

**Live:** https://rons05.github.io/Portfolio_MC/

---

## What's in it

**A WebGL voxel renderer, written from scratch.** Matrix maths, shaders, mesh
building and the texture atlas are all hand-rolled in `script.js`. The page has
no dependencies at all.

**Six worlds.** Each hotbar slot travels to a different biome, rebuilt on the fly:

| Slot | Section | World |
| --- | --- | --- |
| 1 | Profile | Cherry Grove |
| 2 | Builds | Plains |
| 3 | Advancements | Savanna |
| 4 | Inventory | Storage Room (an interior) |
| 5 | The End | The End |
| 6 | Contact | Beach |

**Procedural textures.** An 11-tile atlas — grass, stone, planks, log grain,
leaves, water, and a full-colour chest — is painted pixel by pixel into a canvas
at load time and uploaded as a GL texture.

**A real skin.** The character is six flat boxes plus a second "hat" layer,
UV-unwrapped against a 64×64 skin texture generated in code, the same way the
game lays one out. Alpha cut-out gives the hair its ragged silhouette.

**Animation.** Idle breathing, arm and leg sway, head turning, and a wave every
nine seconds. Limbs rotate about their real joints; the mesh is re-posed each
frame into pre-allocated typed arrays so the render loop allocates nothing.

**Lighting.** A directional sun with N·L shading, warm key light against a cool
sky ambient, ambient occlusion on vertical faces, and ground shadows baked from
the same sun vector. Indoors, lantern light pools onto the floor instead.

## Running it

Any static server will do:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Files

| File | What it holds |
| --- | --- |
| `index.html` | Title screen, menu, HUD, and the section panels |
| `style.css` | Pixel-art UI — the logo, stone buttons, hotbar, panels |
| `script.js` | Renderer, world generation, textures, character, animation |

## Controls

- Click a hotbar slot, or press <kbd>1</kbd>–<kbd>9</kbd>
- <kbd>Esc</kbd> returns to the title screen
- The moon/sun button toggles day and night
- Try "Mine for the Amulet" three times
